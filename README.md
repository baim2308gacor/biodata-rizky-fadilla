# Muhammad Rizky Fadilla — Personal Portfolio

A multi-page React + Vite portfolio with a Dark Editorial / Swiss Grid / Quiet Futuristic visual direction.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Pages

- `/` — Main
- `/biodata` — Biodata lengkap
- `/family` — Family page
- `/hobi` — Hobi dan cita-cita
- `/pendidikan` — Riwayat sekolah
- `/sosial-media` — WhatsApp dan Instagram

## Notes

- Photos are stored in `public/images`.
- Theme preference is saved in localStorage (`mrf-theme`).
- The grid canvas uses purple in Dark Mode and pink in Light Mode.
